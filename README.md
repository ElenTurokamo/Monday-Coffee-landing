# Monday Coffee Shop — Сайт кофейни в Алматы

Современный, адаптивный сайт-лендинг для кофейни Monday Coffee Shop, разработанный с использованием React, TypeScript и Tailwind CSS.

## 🎯 Цели проекта

- **Максимально точно передать атмосферу заведения** — теплый минимализм с акцентом на качество кофе
- **Упростить принятие решения клиентом** — прийти, забронировать, заказать онлайн
- **Закрыть все основные вопросы пользователя** без перехода на сторонние сервисы

## 🎨 Дизайн-философия: Warm Minimalism

### Цветовая палитра
- **Фон**: Кремовый (#FAF8F3) — теплый, приветливый
- **Текст**: Глубокий серый (#2C2C2C) — читаемый, элегантный
- **Акцент**: Терракотовый (#C85A3A) — цвет кофе, энергия
- **Вторичный**: Шалфейный зеленый (#7A9B7F) — природные элементы
- **Границы**: Мягкий тауп (#D4C5B9) — теплый, не резкий

### Типография
- **Заголовки (H1, H2)**: Playfair Display (serif, 600-700 вес) — элегантность
- **Подзаголовки (H3, H4)**: Outfit (sans-serif, 600 вес) — современность
- **Текст**: Inter (sans-serif, 400-500 вес) — читаемость

### Интерактивность
- Плавные переходы (200-300ms)
- Hover-эффекты: смена цвета, масштабирование (1.02x)
- Тени с теплым оттенком (rgba(200, 90, 58, 0.1))
- Анимации входа при скролле

## 📱 Адаптивность

- **Мобильные (< 640px)**: Одноколоночный макет, мобильное меню
- **Планшеты (640px - 1024px)**: Двухколоночный макет для некоторых секций
- **Десктоп (> 1024px)**: Полный трехколоночный макет, оптимальная ширина контента

## 🚀 Технологический стек

- **Frontend**: React 19 + TypeScript
- **Стили**: Tailwind CSS 4 + Custom CSS
- **Компоненты**: shadcn/ui
- **Иконки**: Lucide React
- **Роутинг**: Wouter
- **Сборка**: Vite
